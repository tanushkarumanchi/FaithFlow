FaithFlow — Bible Reading App

FaithFlow is a web application designed to make reading the Bible simple and accessible. It provides a clean interface for users to explore Bible content in English and Telugu.

🌐 Live Demo

"Open FaithFlow" (https://faithflow-navy.vercel.app/)

✨ Features

- 📖 Bible reading interface
- 🌍 English and Telugu reading modes
- 🔗 Share content with others
- 📱 Simple, user-friendly design
- 🚀 Deployed using Vercel

🛠️ Technologies Used

- React
- Vite
- JavaScript
- HTML and CSS
- Vercel for deployment

💻 Run Locally

1. Clone this repository:
   
   git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder:
   
   cd FaithFlow

3. Install dependencies:
   
   npm install

4. Start the development server:
   
   npm run dev

5. Open the local URL shown in your terminal.

🎯 Project Goal

FaithFlow aims to provide a straightforward Bible-reading experience with support for English and Telugu users.
